# Docker-training

## Learning Map

This training keeps its original hands-on examples and adds internals material
to the related day modules.

| Module | Focus |
| --- | --- |
| [Day 01](Day-01/README.MD) | Architecture, lifecycle, isolation, security, and interview review |
| [Day 02](Day-02/Readme.md) | Bridge networking, veth pairs, `docker0`, NAT, and network modes |
| [Day 03](Day03-docker_volume/Readme.md) | Writable layers, volumes, bind mounts, and tmpfs storage |
| [Day 04](Day04-dockerfile/Readme.md) | Image layers, copy-on-write, and OverlayFS / `overlay2` |
| [Day 05](Day05/Readme.md) | `CMD` and `ENTRYPOINT` runtime behaviour |
| [Day 06](Day06-Reduce-image-size/Readme.md) | Build cache and dependency-aware Dockerfile design |
